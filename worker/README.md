# worker

Cloudflare Worker 코드입니다.

- `worker.js`: v6.12 (2026-11-28). v6.12는 초기증액형 감액 후 월지급금을 최초 금액×70%의 10원 단위 반올림으로 계산합니다(v6.11: 일시인출금을 1회차에 반영). 이전 v6.10 내용: v6.10은 `/api/calc`를 추가했습니다. 화면에서 이자율·주택가격상승률에 **99**를 입력하면 Cloudflare 변수 `LONGTERM_AVG_IR`(추정 이자율, 연 %, 숫자만)·`HP_GROWTH_RATE`(상승률, 연 %, 숫자만)로 Worker가 계산해 결과만 돌려줍니다(값은 화면에 나오지 않음). 이전 v6.9 내용: v6.9는 공용 로그인(`/api/login`, 1시간 출입증)을 추가했습니다. 변수 `SESSION_SECRET`(긴 임의 문자열), `LOGIN_ID`, `LOGIN_PW`를 **Secret**으로 만들면 모든 `/api/*`가 출입증을 요구하고, 없으면 기존처럼 동작합니다. 계정을 늘릴 때는 `LOGIN_USERS`에 `아이디:비밀번호,아이디:비밀번호`를 넣습니다. 이전 v6.8 내용: v6.8은 선택 변수 `VWORLD_RELAY_URL`·`VWORLD_RELAY_SECRET`이 있으면 브이월드를 Cloudflare 밖의 중계 서버(`vercel-relay/`)로 호출합니다(Worker에서 직접 호출하면 HTTP 520). 이전 v6.7 내용: v6.7은 브이월드 호출에 브라우저와 같은 Referer·Origin·User-Agent를 보냅니다(Worker에서만 520이 나서). 이전 v6.6 내용: v6.6은 브이월드 호출에 `domain`(발급 때 등록한 URL)을 붙입니다. 이것이 없으면 INCORRECT_KEY가 납니다. 이전 v6.5 내용: v6.5는 대지권등록목록 호출이 실패하면 조건(JSON 500건 → JSON 100건 → XML 100건)을 바꿔 재시도하고 실패 사유를 화면에 보이게 했습니다. 이전 v6.4 내용: v6.3에서 브이월드 대지권 서비스 이름을 `ldragsList`에서 `ldaregList`로 고쳤고, v6.4에서 대지권 목록을 `totalCount`까지 끝까지 읽고 동·호의 앞자리 0을 무시하며 `/api/land` 응답에 진단 정보 `ldareg`를 넣었습니다. **Cloudflare에 배포해야 반영됩니다.**
