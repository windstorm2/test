# 프로젝트 개요

최종 수정: 2026-11-23 10:40

## 1. 명칭

주택연금 상담 및 신청 도구 개발

## 2. 목적

주택연금은 고객마다 필요한 서류가 다르고 선택할 때 고려할 것이 많습니다.
금융지식이 부족하거나 이해에 어려움이 있는 고령의 상담 고객에게 빠르고 정확하게 안내할 수 있도록, 상담 직원이 쓰는 보조도구를 만듭니다.

입력정보 → 설명자료 생성 → 계약서류 자동 완성 및 출력

## 3. 원칙

1. 필요한 정보는 모두 받되, 같은 정보는 한 번만 입력합니다.
2. 입력은 처음에 모두 받거나, 다음 단계에 필요한 정보만 단계마다 이어서 받습니다. (방식은 설계 단계에서 확정)
3. 고객 정보는 어디에도 저장하지 않습니다.
4. 담보방식은 도구가 추천하고, 최종 선택은 고객이 합니다. 추천과 다른 방식도 고를 수 있습니다.
5. VS Code, GitHub, Cloudflare의 무료 한도 안에서 개발하고 운영합니다.
6. 저장소가 공개 상태이므로 인증키와 고객 정보를 코드에 넣지 않습니다. 인증키는 Cloudflare Worker의 Secret으로만 둡니다.

## 4. 활용 흐름과 현재 상태

| 순서 | 단계 | 현재 상태 |
|---|---|---|
| 1 | 신청인 정보 | 있음 (메인 도구 Step 1, 신청서 인적사항은 Step 6) |
| 2 | 주택정보 검색 | 있음 (메인 도구 Step 2) |
| 3 | 연금액 산출 | 있음 (메인 도구 Step 3~4) |
| 4 | 담보방식 선택 | 있음 (메인 도구 Step 5, v6.1). 위험 점수와 기준값은 임시값이며 확정 전. 실제 화면 시험은 남음 |
| 5 | 맞춤형 설명서 | 없음 |
| 6 | 신청서 교부 및 서류 안내 | 있음 (메인 도구 Step 6) |
| 7 | 개인정보 동의서, 확약서, 약정서 출력 | 없음 |
| 8 | 등기서류 출력 | 위임장·확인서면 시제품만 있음. 통합 전 |

"있음"으로 적은 기능의 코드는 루트의 `index.html`, `css/`, `js/`에 있습니다. 나누기 전 원본은 `backup/202611222155/`에 있습니다.

## 5. 기술 환경

| 구분 | 내용 |
|---|---|
| 화면 | HTML, CSS, JavaScript. 빌드 도구 없이 GitHub Pages로 배포 |
| API 중계 | Cloudflare Worker (`https://homepension.windstorm2.workers.dev`) |
| 개발 도구 | VS Code, GitHub |
| 접근 제한 | 지점 접속 토큰을 입력해야 API를 쓸 수 있음 |

## 6. 데이터 출처

| 데이터 | 출처 |
|---|---|
| 예상 월지급금 | 공공데이터포털 HF 월지급금 API |
| 건축물대장(동·호, 면적, 사용승인일 등) | 공공데이터포털 건축HUB |
| 주소 검색 | 도로명주소 API (juso.go.kr) |
| 공시가격, 토지(지목·면적·공시지가) | 브이월드 (공시가격은 없으면 건축HUB) |
| 주택 시세 | HF 시세조회 웹페이지 (내부 협의 완료) |

## 7. 저장소 운영

| 저장소 | 역할 | 주소 |
|---|---|---|
| `windstorm2/test` | 개발용. 모든 수정은 여기서만 함 | https://windstorm2.github.io/test/ |
| `windstorm2/home_pension` | 운영용. 검증된 결과만 반영 | https://windstorm2.github.io/home_pension/ |

- 소스는 계정 안의 어느 저장소에서 가져와도 됩니다.
- 서식(동의서, 확약서, 약정서, 등기서류)은 이 저장소의 `forms/` 폴더에서 개발해 통합합니다.

## 9. 문서 관리 규칙

- 코드나 로직을 고칠 때마다 `docs/CHANGELOG.md`와 관련 문서를 같은 커밋에서 고칩니다.
- 요건은 `docs/REQUIREMENTS.md` 한 곳에만 적습니다. 다른 문서에는 요약과 링크만 둡니다.
- VS Code에서 직접 고친 내용은 자동으로 문서에 반영되지 않으므로 따로 기록해야 합니다.
